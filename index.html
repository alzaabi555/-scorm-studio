إنشاء SCORM 1.2

اختر المجلد للمحافظة على المسارات. جميع الملفات المختارة تُضمّن في الحزمة؛ احذف الأسرار والملفات غير الضرورية مسبقًا.

لم تُضف ملفات

الصفحة المحددة الأولى هي البداية. أعد الإنشاء بعد تعديل الإعدادات أو الملفات.

فتح حزمة جاهزة

حزم SCORM 1.2 فقط. التخزين خاص بهذا المتصفح وليس حسابًا سحابيًا.

ربط التتبع بصفحتك

parent.SCORMBridge.setScore(85);
parent.SCORMBridge.setStatus('passed');
parent.SCORMBridge.saveState({q: 2});
parent.SCORMBridge.getState();
هذه الواجهة للصفحات المغلفة بالأداة. الحزم المستوردة تستخدم SCORM API الأصلي.

المعاينة والتقييم

    أنشئ حزمة أو افتح ZIP للبدء.

    ستظهر هنا الحزمة مع أدوات التفاعل ومراقبة الدرجة والاستئناف.

    ملاحظات النشر

    تعمل هذه النسخة عبر HTTPS على GitHub Pages، بما في ذلك النشر داخل مجلد المستودع. لا تحتاج إلى Python أو مفتاح Gemini API.

    المعاينة محاكاة محلية وليست شهادة مطابقة. تحقق من الحزمة على منصة التعلم المستهدفة قبل استخدامها مع الطلبة.
