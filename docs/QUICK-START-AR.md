# البداية السريعة

هذه حزمة الإصدار 2.0 من «استوديو إنتاج الدروس والأنشطة التفاعلية وتصديرها إلى SCORM». تحتوي الأداة كاملة، ولا تحتاج تنزيل مكتبات واجهة من الإنترنت أثناء استخدامها.

## لتحديث مستودعك

1. احتفظ بنسخة احتياطية من المستودع السابق.
2. ارفع محتويات مجلد `lesson-studio` إلى جذر المستودع، وليس ملف ZIP نفسه.
3. احتفظ بكل ملفات `vendor` وملفات التشغيل.
4. شغّل في AI Studio الأمر `npm run dev`.
5. على GitHub Pages استخدم النشر الثابت من الجذر، أو من ملفات `dist` ضمن إعداد نشر مخصص.

## للتجربة دون إعداد ذكاء اصطناعي

افتح المشروع التجريبي ثم المعاينة. عدّل عنصرًا، واعتمده، واعتمد بقية العناصر بعد مراجعتها، ثم نزّل SCORM.

يمكنك أيضًا كتابة الأسئلة يدويًا. ويمكنك تنزيل طلب مخصص من المحتوى إلى AI Studio ثم استيراد JSON الناتج دون ربط API داخل الأداة.

## للتوليد الآلي من ملفاتك

اضبط `GEMINI_API_KEY` في بيئة الخادم، و`STUDIO_ACCESS_TOKEN` عند النشر خارج localhost. عند فصل الواجهة على GitHub Pages، اضبط أيضًا `ALLOWED_ORIGIN`، وأدخل عنوان خدمة HTTPS ورمز الوصول في إعدادات الأداة.

التفاصيل في `README.md` و`docs/AI-STUDIO.md`. لا تضع مفتاح Gemini في ملفات JavaScript أو مستودع GitHub.

## تذكير

احفظ مشروعك بتنزيل JSON قبل إغلاق الصفحة. حزمة SCORM للتشغيل على المنصة، وملف المشروع للعودة إلى التحرير؛ الأداة لا تجمع أسماء الطلبة أو درجاتهم.
