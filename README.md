# استوديو إنتاج الدروس والأنشطة التفاعلية وتصديرها إلى SCORM

إصدار 2.0.0. أداة تأليف عربية للمعلم تحول المحتوى الذي يختاره إلى شرح وأسئلة وأنشطة قابلة للتحرير والمعاينة، ثم تصدّر HTML مستقلًا أو حزمة SCORM 1.2. هذا إصدار كامل مبني وفق مواصفات الحوار؛ لم تتوفر ملفات مستودعك السابق للمقارنة أو الدمج، لذلك احتفظ بنسخة منه قبل الاستبدال.

## ابدأ هنا

- **التجربة السريعة:** شغّل الأداة واضغط «فتح المشروع التجريبي». يتضمن المثال القوالب العشرة، ويمكن تعديله وتجربته واعتماده وتصديره.
- **عملك الحقيقي:** أضف PDF أو صورًا أو نصًا، وافتح «مراجعة النص»، ثم اختر نمط الإنتاج وأنواع العناصر وأعدادها.
- **الحفظ:** اضغط «حفظ المشروع» لتنزيل JSON. لا يوجد حفظ تلقائي؛ إغلاق الصفحة دون حفظ يفقد العمل، وملف المشروع يتضمن المصادر الأصلية المختارة.
- **التصدير:** راجع المحتوى واعتمده من المحرر، ثم نزّل حزمة SCORM. رفع ZIP إلى LMS خطوة يقوم بها المعلم خارج الأداة.

## ما الذي يعمل مباشرة؟

| الوظيفة | التشغيل |
|---|---|
| قراءة النص في PDF ورفع صور الصفحات | محليًا داخل المتصفح |
| تحرير النصوص والأسئلة والإجابات والمصادر | محليًا داخل المتصفح |
| إضافة أسئلة وأنشطة يدويًا | دون ذكاء اصطناعي |
| المعاينة التفاعلية | محليًا، دون Service Worker للمحتوى المؤلّف |
| تنزيل HTML وSCORM والمشروع JSON | محليًا داخل المتصفح |
| توليد أسئلة ودروس آليًا من النص | يحتاج خدمة خلفية مفعّلة أو نقل طلب إلى AI Studio |
| قراءة صور وPDF ممسوح ضوئيًا ذكيًا | يحتاج خدمة خلفية مفعّلة؛ يمكن إدخال النص يدويًا بدلًا منها |
| تشغيل ZIP مستورد أو محتوى HTML متعدد الملفات | يحتاج Service Worker في موقع HTTPS أو localhost |

الأداة لا تختلق نتائج عند غياب خدمة التوليد. تُظهر رسالة واضحة، وتظل أدوات التحرير والتصدير والتبادل مع AI Studio متاحة.

## التشغيل في AI Studio أو على جهازك

يتضمن المشروع `package.json` و`package-lock.json` دون تبعيات npm خارجية. ملفات PDF.js وfflate والخط مضمنة في `vendor` لتجنب اعتماد قراءة PDF والتصدير على CDN.

```bash
npm ci
npm run dev
```

افتح عنوان الخادم المحلي الذي تستخدمه بيئة التشغيل؛ المنفذ الافتراضي 3000، ويقرأ الخادم `PORT` إذا ضبطته الاستضافة. استخدم Node.js 20.20 أو أحدث، وأبقِ الخادم يعمل أثناء الاستخدام.

```bash
npm test
npm run build
```

ينتج البناء مجلد `dist` ثابتًا لا يتضمن الخادم أو ملف البيئة. قد تمنع نافذة AI Studio الداخلية Service Worker؛ في هذه الحالة تعمل معاينة الدروس المؤلّفة، لكن معاينة ZIP المستورد يجب تجربتها من رابط الموقع المنشور.

## النشر على GitHub Pages

1. خذ نسخة احتياطية أو استخدم فرعًا جديدًا في مستودعك.
2. فك ضغط الحزمة، وارفع محتويات مجلد الأداة إلى الجذر، بحيث يكون `index.html` بجانب `package.json` و`app.js`.
3. أبقِ مجلد `vendor` وملفات `sw.js` و`legacy-player.html` و`legacy-player.js` في مواقعها.
4. إذا كنت تنشر من الفرع بالفعل، استخدم إعدادك الحالي. أو من Settings ثم Pages اختر النشر من `main` و`/(root)`.
5. افتح رابط GitHub Pages، وليس رابط الملف داخل مستودع GitHub.
6. جرّب المثال، وصدّره، ثم افتح ZIP الناتج من أدوات HTML وSCORM.

يمكن نشر ملفات `dist` فقط بدل الجذر إذا كانت لديك آلية نشر مخصصة. GitHub Pages يقدم الملفات الثابتة ولا يشغّل `server.mjs`، لذلك يحتاج التوليد المباشر إلى خدمة خلفية منفصلة، بينما تعمل بقية وظائف المتصفح دونها.

## تفعيل Gemini بصورة صحيحة

مفتاح Gemini يوضع في بيئة الخادم فقط، وليس في `app.js` أو `config.js` أو مستودع عام. هذا الفصل متوافق مع توصية Google بعدم كشف مفاتيح API في تطبيقات الويب العميلة ([إرشادات أمان المفاتيح](https://ai.google.dev/gemini-api/docs/api-key)).

### عندما يشغّل AI Studio خادم Node

اضبط سرًا بيئيًا باسم `GEMINI_API_KEY` من إعدادات الأسرار المتاحة في بيئة تشغيلك. إذا كانت البيئة لا توفر حقن الأسرار للخادم، استخدم استضافة Node منفصلة بدل وضع المفتاح في الواجهة.

للتشغيل المحلي فقط، انسخ `.env.example` إلى `.env` وأدخل القيم على جهازك. ملف `.env` مستبعد من Git ولا يخدمه خادم الويب.

```text
GEMINI_API_KEY=قيمة_سرية_في_بيئة_الخادم_فقط
GEMINI_MODEL=gemini-3.8-flash
STUDIO_ACCESS_TOKEN=رمز_وصول_خاص_قوي
PORT=3000
```

اسم النموذج قابل للتعديل بحسب ما هو متاح لحسابك. التنفيذ يستخدم REST generateContent ومخرجات JSON ذات مخطط محدد كما في [وثائق Google للمخرجات المنظمة](https://ai.google.dev/gemini-api/docs/generate-content/structured-output?authuser=14).

### عندما تعمل الواجهة على GitHub Pages

1. شغّل `server.mjs` على استضافة تدعم Node.js.
2. اضبط `GEMINI_API_KEY` و`STUDIO_ACCESS_TOKEN` على الخادم.
3. اضبط `ALLOWED_ORIGIN` إلى أصل موقع GitHub Pages مثل `https://YOUR-ACCOUNT.github.io`، دون مسار المستودع ودون شرطة مائلة أخيرة.
4. من «إعداد التوليد» داخل الأداة، أدخل عنوان خدمة HTTPS ورمز الوصول الخاص.
5. اختبر الاتصال، ثم وافق على إرسال المحتوى المحدد عند أول طلب توليد.

يمكن وضع عنوان الخدمة العام فقط في `config.js` لتثبيته بدل إدخاله كل جلسة. لا تضع رمز الوصول أو مفتاح Gemini فيه.

رمز الوصول حماية لخدمة معلم أو فريق خاص، وليس نظام حسابات متعدد المستخدمين. إذا أردت إتاحة التوليد للعموم، أضف مصادقة فعلية وحصص استخدام وفوترة ورصد إساءة الاستخدام أولًا؛ لا تنشر مفتاح الخدمة أو رمزها في موقع عام.

## استخدام AI Studio دون ربط API

1. أضف المصدر وراجع نصه.
2. حدد نمط الإنتاج وأعداد الأنواع.
3. اضغط «تنزيل طلب جاهز لـ AI Studio».
4. استخدم الطلب في محادثة AI Studio، واطلب استجابة JSON مطابقة للمخطط، دون سياج Markdown.
5. احفظ الاستجابة في ملف `.json`.
6. اضغط «استيراد مسودة JSON» في الأداة.

تتحقق الأداة من الأنواع والأعداد والإجابات ومراجع المصدر والاقتباسات. إذا تغيرت المصادر أو الإعدادات بين تصدير الطلب واستيراد الجواب، قد يُرفض الجواب؛ أعد طلب التوليد من الإعدادات الحالية.

هذا المسار لا ينفذ إرسالًا تلقائيًا ولا يستهلك API من الأداة. قراءة صورة ممسوحة ضوئيًا في هذا المسار تتطلب نسخ نصها من AI Studio يدويًا إلى شاشة مراجعة المصدر.

## أنواع المحتوى المنفذة

- **اختيار من متعدد:** إجابة واحدة، مع خيارات قابلة للتحرير.
- **اختيار عدة إجابات:** تصحيح المجموعة كاملة.
- **صح أو خطأ:** خياران ثابتان وإجابة واحدة.
- **إكمال الفراغ:** مقارنة نصية محلية مع بدائل معتمدة، مع تجاهل التشكيل والمسافات الزائدة.
- **إجابة قصيرة أو تعليل:** كتابة الإجابة ثم مقارنتها بإجابة نموذجية؛ لا حكم آلي على الإجابة المفتوحة.
- **توصيل:** اختيار الوصف المناسب لكل عنصر، مناسب للوحة المفاتيح والهاتف.
- **ترتيب:** خطوات مخلوطة مع أسهم تحريك، لا يحتاج السحب والإفلات.
- **تصنيف:** اختيار الفئة المناسبة لكل عنصر.
- **بطاقات كشف:** عنوان يُفتح لإظهار المعلومة.
- **شرح تفاعلي:** نص وصورة وتنقل بين الصفحات.

يمكن طلب نوع واحد فقط أو توزيع الأعداد على عدة أنواع. يدعم المحرر الإضافة والنسخ والحذف وإعادة الترتيب وتغيير النوع وإعادة توليد عنصر واحد واعتماد كل عنصر أو المجموعة كاملة.

## حدود واضحة

- **النطاق:** لا أسماء طلبة، لا حسابات طلبة، لا قاعدة نتائج، لا تقارير درجات.
- **SCORM المؤلف هنا:** يرسل حالة الإكمال وآخر صفحة ومدة الجلسة فقط إلى LMS. لا يرسل الدرجة ولا تفاصيل الإجابات، ولا يتصل بموقع التأليف وقت الدراسة.
- **الإكمال:** يتحقق عند ضغط «إنهاء المحتوى»، ولا يعني إتقان جميع الأنشطة.
- **الاستئناف:** يستعيد موضع الصفحة إذا حفظه LMS. لا يحفظ إجابات الأنشطة بين الجلسات.
- **الأسئلة المفتوحة:** للمقارنة الذاتية، وليست تصحيحًا ذكياً لإجابة الطالب.
- **النص المعتمد:** هو أساس التوليد. الأرقام والمعادلات وترتيب العربية وOCR تحتاج مراجعة بشرية.
- **صور المصدر:** يمكن تضمين صورة الصفحة كاملة في أي عنصر؛ لا يوجد محرر قص الصور أو استخراج تلقائي مستقل لكل رسم.
- **قوالب لا كود حر:** لا توليد لمحاكاة علمية حرة أو HTML اعتباطي؛ القوالب هي من تنفذ التفاعل.
- **ملفات المصدر:** حتى 20 MB للملف و40 صفحة للـPDF و100 صفحة/مصدر بالمشروع. حتى 40 مصدرًا نصيًا و70 ألف حرف في طلب التوليد الواحد، و30 عنصرًا في الدفعة.
- **ZIP المستورد:** حتى 50 MB مضغوطًا و100 MB بعد الفك و2000 ملف. مسارات الخروج من المجلد تُرفض، وxml:base غير مدعوم.
- **محتوى موثوق فقط:** مشغّل ZIP القديم ليس صندوق عزل أمنيًا؛ قد ينفذ المحتوى اتصالات بالإنترنت أو يحاول الوصول إلى أصل الموقع.
- **حزم مستوردة:** لا نعيد كتابة كودها ولا نزيل اتصالاتها أو سلوكها على LMS. سياسة «لا درجات» تخص المحتوى المؤلف بالقوالب هنا؛ محاكي ZIP المحلي يتجاهل حقول الاسم والدرجة والتفاعلات.
- **تغليف HTML:** يحافظ على الملفات والمسارات النسبية، ولا يحوّل PHP أو الخوادم ولا يصلح المسارات المطلقة أو الخدمات الخارجية.
- **معاينة ZIP:** في الذاكرة فقط، وقد تنتهي إذا أوقف المتصفح Service Worker؛ أعد فتح الحزمة عندها.
- **التوافق:** الاختبارات المرفقة ليست اعتماد SCORM ولا اختبارًا فعليًا على LMS. اختبر الحزمة على المنصة التي تستخدمها قبل النشر للطلاب.

## ملفات المشروع

```text
index.html / style.css / app.js   واجهة المعلم
schema.js                        القوالب والتحقق ومخطط التوليد
runtime.js                       تشغيل الأنشطة في الدرس
exporter.js                      HTML وZIP وSCORM
demo.js                          مشروع تجريبي للقوالب العشرة
vendor/                          PDF.js وfflate وخط عربي مع الرخص
api.mjs / server.mjs              خدمة Gemini وخادم التطوير
sw.js / legacy-player.*          معاينة حزم ZIP الموثوقة
build.mjs                        بناء نسخة ثابتة
tests/                           اختبارات وحدات
docs/                            دليل AI Studio ونتائج الاختبار
```

## الخصوصية والحفظ

تُقرأ الملفات في ذاكرة المتصفح. التوليد المباشر يرسل النص المحدد فقط، وقراءة الصورة ترسل تلك الصورة بعد موافقتك؛ أما سياسات الاحتفاظ لدى مزود الخدمة فتخضع لحسابك وشروطه.

لا يكتب الخادم محتوى الطلبات في ملفات، ولا يسجل نصها في سجل التطبيق. حزمة الطالب تتضمن عناصر الدرس والصور المرتبطة بها والخط والتفاعل، ولا تتضمن ملفات المصدر غير المستخدمة أو إعداد الخدمة أو مفتاحها.

## سياق الاختبارات

اختُبرت أدوات المتصفح والتصدير واستيراد الحزمة في Chromium. اختُبر التوليد والقراءة الذكية في المعاينة الخاصة بمحول خدمة مختلف؛ محول Gemini المرفق اختُبر باختبارات العقد والاستجابات المحاكية فقط لعدم توفير مفتاح Gemini.

راجع `docs/TEST-RESULTS.md` للفصل بين ما اختُبر محليًا وما اختُبر على رابط المعاينة وما لم يُختبر. لا تعتبر نجاح محول الاختبار إثباتًا لنجاح إعداد Gemini في حسابك.
